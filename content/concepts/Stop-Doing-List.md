# Stop Doing List

## 定义
段永平管理哲学中的核心工具：在执行层面，比"应该做什么"更优先的是"不应该做什么"。Stop Doing List（停止做清单）是"做对的事情"的实操形式——先定义并移除错误行为，比添加正确行为对企业/个人的影响更为深远。

> "Stop doing list比to-do list重要。"
> — [[sources/duan/【文章目录】/2-对外演讲、采访/09-2018-段永平斯坦福交流|09-2018-段永平斯坦福交流]]

## 起源
段永平大学三年级时读到德鲁克（Peter Drucker）的一句话：**"做对的事情和把事情做对"**（Do the right things and do things right）。他由此意识到"做对的事情"等价于"不做不对的事情"，并逐渐形成Stop Doing List这一实践工具。

> "做对的事情，说穿了就是不做不对的事情。"
> — [[sources/duan/【文章目录】/2-对外演讲、采访/09-2018-段永平斯坦福交流|09-2018-段永平斯坦福交流]]

## 核心阐释

### 1. 逻辑结构
Stop Doing List是[做对的事情把事情做对](做对的事情把事情做对.md)的"反面工程"：
- **正向**：做对的事情 → 建立to-do list
- **逆向**：不做错的事情 → 建立stop doing list
- 两者是同一逻辑的正反表述，但在实践中**stop doing list往往更易操作、效果更显著**

### 2. 企业层面——OPPO/vivo的Stop Doing List实例

段永平在讲述步步高生态时，将以下行为列为明确的"不做"：

| 类别 | 不做事项 | 逻辑 |
|---|---|---|
| 渠道 | 不做ODM/OEM代工 | 代工伤害品牌、损失利润率，偏离消费者导向 |
| 定价 | 不做差价销售（窜货） | 破坏渠道信任，损害消费者利益 |
| 销售 | 不设专职销售部门（vivo早期） | 产品力才是核心，销售是结果不是驱动 |
| 财务 | 不借有息贷款扩张 | 负债经营放大风险，偏离"本分" |
| 品类 | 不进入能力圈之外的业务 | "有多大能力做多大事"（见[能力圈](能力圈.md)） |

> "我们这么多年做的一件重要的事情就是：我们不做什么。"
> — [[sources/duan/【文章目录】/2-对外演讲、采访/09-2018-段永平斯坦福交流|09-2018-段永平斯坦福交流]]

### 3. 投资层面
价值投资实践中的Stop Doing List：
- 不借钱投资（巴菲特忠告："I just want to get rich only once"）；段永平明确："我们在投资上也从不借钱（margin）"
- 不投不懂的公司
- 不频繁交易（持仓即持有公司）
- 不预测短期股价走势
- 不考虑牛市熊市策略差异（"想着牛熊市本身就是投机"）

### 4. 个人层面
- 停止抱怨（抱怨消耗能量但不改变现实）
- 停止浪费时间的习惯
- 停止与价值观不符的社交

### 5. 步步高Stop Doing List完整案例（2016年博文披露）
段永平在"不秘诀"文章中列出步步高的具体不做事项：
- **不做OEM**（陈明永最早提出，约20年前）：专业OEM公司更擅长，做不过他们，干脆不做
- **不讨价还价**：建立统一定价体系，所有客户同等价格，无折扣无返点
- **不赊账**
- **不拖付货款**
- **不晚发工资**
- **不做不诚信的事情**
- **不攻击竞争对手**
- **不向银行贷款**（有充裕信用额度但不使用）

> "好的公司都一定是有一个长长的'Stop doing list'，就是'不做的事情'。"
> — [[sources/duan/【文章目录】/4-网易博客集/025-"不秘"诀：本分+平常心|025-"不秘"诀：本分+平常心]]（2016年）

## 早期来源：562号博文直接定义（2010年）

562号博文（562-什么是对的事情.md）是段永平最早将"做对的事情"与Stop Doing List显式连接的来源：

> "做对的事情，说穿了，就是不做不对的事情，而且发现错了马上改，不管多大的代价都是最小的代价。"
> — [[sources/duan/【文章目录】/4-网易博客集/562-什么是对的事情|562-什么是对的事情]]（2010年）

在同一博文的评论中，段永平进一步强调了"发现错了马上改"的重要性，拖延纠错代价会越来越大。这篇博文是理解Stop Doing List概念最早且最直接的一篇原始文本。

## 与[本分](本分.md)的关系
本分在价值观层面界定"什么是对的事情"，Stop Doing List在操作层面提供"不做哪些错事"的具体清单。本分是判断标准，Stop Doing List是执行工具。

## 与其他概念的关系
- [做对的事情把事情做对](做对的事情把事情做对.md)：同一逻辑的正反两面
- [本分](本分.md)：价值观基础，指引"什么不该做"的判断
- [能力圈](能力圈.md)：能力圈之外的事进入Stop Doing List
- [价值投资](价值投资.md)：投资中的Stop Doing List是价值投资纪律的实践

## 在雪球问答录中的阐释

### Stop Doing List的来源：过程发现 + 本分约束（Q1325，2019年）

> "不做的事情有些事在过程中发现的，比如给人加工，有些是本分带来的，比如不能不诚信。不做的事情让我们减少犯错的机会，日积月累效果很好。"
> — [[sources/duan/【文章目录】/3-雪球问答录/段永平雪球问答录_杨不为整理-仅保留首轮对话版-2025年10月|段永平雪球问答录_杨不为整理-仅保留首轮对话版-2025年10月]]（Q1325）

### Stop Doing List的长度与边界（Q1484，2019年）

> "我没有真的统计过我们的stop doing list有多少条，但似乎不是几十条那么多。所谓stop doing list指的都是不对的事情，但要列入这个清单的东西一定要尽量少，不然可能会束缚大家的手脚。你说的抱怨的东西有时候未必就是不对的事情。抱怨往往是老板们需要收集并改进的东西。"
> — [[sources/duan/【文章目录】/3-雪球问答录/段永平雪球问答录_杨不为整理-仅保留首轮对话版-2025年10月|段永平雪球问答录_杨不为整理-仅保留首轮对话版-2025年10月]]（Q1484）

这一回答修正了一个常见误解：Stop Doing List不是越长越好，只有"不对的事情"才进清单，而"抱怨"之类的东西则属于管理层应收集改进的信息，而非禁止项。

### 最生动的案例：不做代工（Q1577，2019年）

> "我们stop doing list上很多事情都是有例子的。记得有次和台湾做代工的一个大佬吃饭聊天，他也问到为什么你们这么厉害，我说因为我们有个'stop doing list'，他也问到'举个例子？'，我说：比如我们不做代工。他马上问：为什么？我说，如果我们做代工的话很难和你们竞争哈。"
> — [[sources/duan/【文章目录】/3-雪球问答录/段永平雪球问答录_杨不为整理-仅保留首轮对话版-2025年10月|段永平雪球问答录_杨不为整理-仅保留首轮对话版-2025年10月]]（Q1577）

### "做对的事情"即停止做错的事情（Q1648，2019年）

> "所谓做对的事情是体现在停止做错的事情上的，发现是错的事情就赶紧停。"
> — [[sources/duan/【文章目录】/3-雪球问答录/段永平雪球问答录_杨不为整理-仅保留首轮对话版-2025年10月|段永平雪球问答录_杨不为整理-仅保留首轮对话版-2025年10月]]（Q1648）

### Stop Doing List = 不为清单（Q1924，2019年）

> "你爸爸说的我们知道什么不能做这个说法是非常对的，这就是我们的stop doing list，就是所谓的不为清单。"
> — [[sources/duan/【文章目录】/3-雪球问答录/段永平雪球问答录_杨不为整理-仅保留首轮对话版-2025年10月|段永平雪球问答录_杨不为整理-仅保留首轮对话版-2025年10月]]（Q1924）

此处段永平明确将"stop doing list"与中文"不为清单"画等号，也印证了《论语》"知其不可为而为之"的反面——即"知其不可为而不为之"的智慧。

### 个人也应积累自己的Stop Doing List（Q2026，2019年）

> "我不在位很多年，不知道现在的stop doing list，但每个人最好去积累自己的stop doing list会比较有效果。"
> — [[sources/duan/【文章目录】/3-雪球问答录/段永平雪球问答录_杨不为整理-仅保留首轮对话版-2025年10月|段永平雪球问答录_杨不为整理-仅保留首轮对话版-2025年10月]]（Q2026）

## 077雪球小摘：巴菲特最厉害处在于坚持不做不对的事（2014年，077号博文）

077号博文（077-引用【转载】段永平投资思想 ---雪球小摘.md）的#31和#32两条是段永平将Stop Doing List与巴菲特和个人信仰挂钩最直接的表述：

> "巴菲特之所以能够如此厉害，最重要的一点就是他能坚持不做他认为不对的事情。要坚持这点其实非常不容易，因为往往'不对的事情'往往是有短期诱惑的。"
> — [[sources/duan/【文章目录】/4-网易博客集/077-引用 【转载】段永平投资思想 ---雪球小摘|077-引用 【转载】段永平投资思想 ---雪球小摘]]（#31）

> "我对信仰的理解就是'做对的事情'，或者说知道是'不对的事情'就别做了。人们热爱做'不对的事情'是因为这类事情往往有短期诱惑。"
> — [[sources/duan/【文章目录】/4-网易博客集/077-引用 【转载】段永平投资思想 ---雪球小摘|077-引用 【转载】段永平投资思想 ---雪球小摘]]（#32）

#31是段永平对巴菲特最重要特质的判断——不是选股能力，而是"坚持不做不对的事情"。这将巴菲特的成就直接归因于Stop Doing List的执行力。#32将这一原则提升到"信仰"层面，揭示了短期诱惑是"不对的事情"持续存在的根本原因。
